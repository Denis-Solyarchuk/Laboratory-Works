# Лабораторні роботи з програмування на C++/CLI

Цей репозиторій створено для зберігання лабораторних робіт, виконаних у середовищі Microsoft Visual Studio мовою C++/CLI з використанням платформи .NET.

У репозиторії представлені лабораторні роботи №1 та №5, присвячені математичним обчисленням, обробці введених даних і роботі з одновимірними масивами.

## Лабораторна робота №1 — Розрахунок вартості килимового покриття

**Мета:** Розробити консольну програму для обчислення площі кімнати та загальної вартості килимового покриття.

Програма приймає від користувача номер варіанта `N`, на основі якого визначаються розміри кімнати та вартість одного квадратного метра покриття.

Основні можливості програми:
- Обчислення довжини та ширини кімнати за заданими формулами.
- Визначення загальної площі приміщення.
- Розрахунок вартості килимового покриття.
- Перевірка введених даних на коректність.
- Виведення результатів із точністю до двох знаків після коми.

**Приклад:** Якщо користувач вводить `N = 5`, розміри кімнати становитимуть 15 × 10 метрів, площа — 150 м², а загальна вартість покриття — 750 доларів.

## Лабораторна робота №5 — Поелементний обмін значеннями масивів

**Мета:** Ознайомитися з принципами створення та обробки одновимірних масивів, використанням циклів і допоміжних функцій.

Програма створює два цілочисельні масиви `A` та `B`, кожен із яких містить шість елементів.

Основні можливості програми:
- Створення та ініціалізація двох одновимірних масивів.
- Виведення початкових значень масивів у консоль.
- Поелементний обмін значеннями між масивами за допомогою циклу `for`.
- Використання тимчасової змінної для збереження значень під час обміну.
- Виведення результатів за допомогою окремої функції `PrintArray()`.

**Приклад:**

До обміну:

```text
A = [10, 20, 30, 40, 50, 60]
B = [99, 88, 77, 66, 55, 44]
```

Після обміну:

```text
A = [99, 88, 77, 66, 55, 44]
B = [10, 20, 30, 40, 50, 60]
```

## Використані технології

- **C++/CLI** — мова програмування.
- **Microsoft Visual Studio** — середовище розробки.
- **.NET Framework** — платформа для виконання програм.
- **Git та GitHub** — інструменти контролю версій і зберігання програмного коду.

## Призначення репозиторію

Репозиторій створено в межах лабораторної роботи №10 «Вебсервіс GitHub» для отримання практичних навичок роботи із системою контролю версій.

Робота з GitHub дозволяє зберігати програмні проєкти, відстежувати історію змін, створювати окремі гілки для розробки та використовувати Pull Request для перевірки й обговорення змін у коді.

## Висновок

Виконання лабораторних робіт №1 та №5 допомогло закріпити практичні навички програмування мовою C++/CLI, зокрема роботу з математичними операціями, умовними конструкціями, циклами, функціями та масивами.

Використання GitHub забезпечує зручне зберігання програмного коду, контроль його версій та можливість спільної роботи над проєктами.
