# Лабораторні роботи з програмування на C++/CLI

Цей репозиторій містить лабораторні роботи №1 та №5, виконані мовою **C++/CLI** з використанням платформи **.NET**.

У процесі виконання робіт було розглянуто основні принципи програмування: роботу зі змінними, математичні обчислення, обробку введених даних, використання масивів, циклів та функцій.

## Лабораторна робота №1 — Розрахунок вартості килимового покриття

Перша програма призначена для обчислення площі кімнати та загальної вартості килимового покриття.

Користувач вводить номер свого варіанта `N`, після чого програма автоматично визначає:

- **Довжину кімнати:** `N + 10` метрів.
- **Ширину кімнати:** `N + 5` метрів.
- **Площу кімнати:** довжина × ширина.
- **Ціну за 1 м² покриття:** `N` доларів.
- **Загальну вартість:** площа × ціна за 1 м².

Програма також перевіряє правильність введених даних і виводить повідомлення про помилку, якщо користувач вводить текст замість числа або недопустиме значення.

**Приклад роботи програми для N = 5:**

```text
Enter your number: 5

The room size is 15.00 by 10.00 meters
The area of the room is 150.00 square meters
Carpet price $750.00
```

## Лабораторна робота №5 — Поелементний обмін значеннями масивів

Друга програма демонструє роботу з одновимірними масивами та циклом `for`.

У програмі створюються два цілочисельні масиви `A` і `B`, кожен із яких містить шість елементів.

Спочатку програма виводить початкові значення обох масивів. Після цього виконується поелементний обмін: кожен елемент масиву `A` міняється місцями з відповідним елементом масиву `B`.

Для обміну використовується допоміжна змінна `temp`, яка тимчасово зберігає значення елемента.

**Приклад результату:**

```text
Початкові масиви:

A: [10, 20, 30, 40, 50, 60]
B: [99, 88, 77, 66, 55, 44]

Масиви після обміну:

A: [99, 88, 77, 66, 55, 44]
B: [10, 20, 30, 40, 50, 60]
```

Для зручного відображення результатів створено окрему функцію `PrintArray()`, яка виводить назву масиву та його елементи.
